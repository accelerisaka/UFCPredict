# UFCPredict

收集 UFC 官网已经确定对手的未来比赛，展示双方在 UFC.com 上的身高、臂展、战绩等资料，并按 Polymarket 实时买入价做模拟预测。

每一场预测固定记 100 美元。点击时锁定该选手的买入价，比赛结束后：

- 猜中：返还 `100 ÷ 锁定价格`
- 未猜中：返还 0
- 平局、无效比赛：退回 100 美元
- 比赛取消，或赛前更换对手：立刻取消未结算的预测，退回 100 美元，并在个人页保留记录。对阵换人后可以重新预测。自己点取消则直接删除这次预测，不留记录

个人页会显示预测准确率、累计投入、已返还和目前盈亏。未结束的预测计入投入，不计入盈亏。准确率不包含走盘。

这是本地模拟账本，不会向 Polymarket 提交真实订单。

## 运行

```bash
npm install
npm run dev
```

打开 http://localhost:3000 。第一次同步赛程和选手页大约需要一两分钟。之后每 15 分钟刷新一次赛程；赛事页每 15 秒刷新一次赔率。

也可以手动同步：

```bash
npm run sync
```
